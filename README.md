# 고구마와 함께하는 한국어 받아쓰기

초급 한국어 단어 20개를 듣고 입력하며 연습하는 웹앱입니다. 10개씩 두 개의 미션으로 나뉘어 있습니다.

## 사용 방법

1. `index.html`을 브라우저에서 엽니다. (음성 기능은 웹 서버로 열 때 더 잘 동작합니다.)
2. **Listen**을 눌러 단어를 듣고, 한국어로 입력한 뒤 **Check**를 누릅니다.
3. 한 미션의 단어 10개를 익히면 다음 미션이 열립니다.

완료 기록은 현재 브라우저에만 저장됩니다. 브라우저의 사이트 데이터를 지우면 기록도 사라집니다. 서버나 외부 서비스로 기록을 보내지 않습니다.

## 내 컴퓨터에서 미리 보기

Python이 설치되어 있다면 이 폴더에서 `python -m http.server 8000`을 실행한 뒤 브라우저에서 `http://localhost:8000`을 여세요.
